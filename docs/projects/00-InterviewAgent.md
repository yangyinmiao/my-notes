# 模拟面试项目

[仓库地址](https://github.com/yangyinmiao/interview-agent)

## 为什么做

因为我发现在准备面试的时候，经常像一个无头苍蝇一样，不知道怎么准备面试，以为自己懂了某个知识点，但面试的时候表达不清晰，或者面试官问了一个没有准备过的问题，就完全懵了，感觉自己面试能力很差。于是我想做一个模拟面试的平台，帮助自己和其他求职者提升面试技能。

---

## 目标

1. 提供一个模拟面试的平台，用户可以提前练习面试
2. 支持用户上传自己的简历，JD，还有题库，进行个性化的面试模拟
3. 提供面试反馈和建议，帮助用户提升面试能力
---

## 技术选型

前端选择的是Next.js
后端是FastAPI + Celery + Redis
数据库是MinIO，PostgreSQL
向量数据库选择Qdrant
使用了LangGraph进行多Agent编排，还集成了LangFuse进行日志记录和分析
