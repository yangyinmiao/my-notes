# 结构化输出

> 目标：让 LLM 稳定输出 JSON 或固定格式数据，而不是随机的自然语言。

---

## 一、为什么需要结构化输出？

LLM 默认输出自然语言，但实际开发中需要机器可解析的格式：

- Agent 工具调用需要解析参数
- 信息抽取需要返回固定字段
- 分类任务需要返回枚举值
- 数据库写入需要固定 schema

**不做结构化输出的问题**：LLM 可能在 JSON 前后加解释文字、格式不稳定、字段名随机变化。

---

## 二、三种方式对比

| 方式 | 稳定性 | 实现复杂度 | 适用场景 |
|------|--------|-----------|---------|
| Prompt 指定格式 | 🟡 中 | 低 | 快速验证、简单场景 |
| JSON Mode | 🟢 高 | 低 | 保证输出合法 JSON |
| Structured Output（schema） | 🟢 最高 | 中 | 需要精确字段和类型 |

---

## 三、方式一：Prompt 指定格式

最简单，但不可靠：

```python
prompt = """
从以下文本中提取报销信息，返回 JSON，字段为：
- amount: 金额（数字）
- category: 类别（差旅费/餐饮费/办公用品）
- date: 日期（YYYY-MM-DD）

文本：高铁票 580 元，2024-03-15，北京到上海出差

只返回 JSON，不要其他内容。
"""
```

**风险**：模型可能加 ```json 代码块、加解释文字，需要手动解析。

---

## 四、方式二：JSON Mode

OpenAI API 支持，保证输出合法 JSON，但不保证字段结构：

```python
response = client.chat.completions.create(
    model="gpt-4o",
    response_format={"type": "json_object"},  # 开启 JSON Mode
    messages=[
        {"role": "system", "content": "你是信息提取助手，总是返回 JSON"},
        {"role": "user", "content": "提取：高铁票 580 元，2024-03-15"}
    ]
)

import json
data = json.loads(response.choices[0].message.content)
```

**注意**：System Prompt 必须提到 JSON，否则 API 报错。

## 五、方式三：Structured Output（推荐）

OpenAI 最新方式，用 Pydantic 定义 schema，**保证字段名、类型、枚举值**完全符合定义：

```python
from pydantic import BaseModel
from enum import Enum
from openai import OpenAI

client = OpenAI()

class ExpenseCategory(str, Enum):
    travel = "差旅费"
    meal = "餐饮费"
    office = "办公用品"

class ExpenseInfo(BaseModel):
    amount: float
    category: ExpenseCategory
    date: str           # YYYY-MM-DD
    description: str

response = client.beta.chat.completions.parse(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "从文本中提取报销信息"},
        {"role": "user", "content": "高铁票 580 元，2024-03-15，北京到上海出差"}
    ],
    response_format=ExpenseInfo,  # 传入 Pydantic 模型
)

expense = response.choices[0].message.parsed  # 直接拿到 ExpenseInfo 对象
print(expense.amount)    # 580.0
print(expense.category)  # ExpenseCategory.travel
```

**优势**：
- 输出直接是 Pydantic 对象，无需手动解析
- 字段类型自动校验
- 枚举值强制限定，不会出现"机票费"这种非法值

## 六、LangChain 方式（with_structured_output）

```python
from langchain_openai import ChatOpenAI
from pydantic import BaseModel

class ExpenseInfo(BaseModel):
    amount: float
    category: str
    date: str

llm = ChatOpenAI(model="gpt-4o")
structured_llm = llm.with_structured_output(ExpenseInfo)

result = structured_llm.invoke("高铁票 580 元，2024-03-15，北京到上海")
print(result.amount)  # 580.0
```

## 七、实用技巧

**处理可选字段**：
```python
from typing import Optional

class ExpenseInfo(BaseModel):
    amount: float
    category: str
    date: Optional[str] = None     # 允许为空
    note: Optional[str] = None
```

**嵌套结构**：
```python
class LineItem(BaseModel):
    name: str
    amount: float

class ExpenseReport(BaseModel):
    applicant: str
    items: list[LineItem]          # 嵌套列表
    total: float
    status: str
```

**提取失败兜底**：
```python
try:
    result = structured_llm.invoke(user_input)
except Exception as e:
    # 结构化输出失败时，回退到普通输出 + 手动解析
    result = fallback_parse(llm.invoke(user_input))
```
