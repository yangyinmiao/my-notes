# Agent 规划策略

> 目标：理解主流规划范式的原理与区别，知道什么场景用什么策略。

---

## 推荐学习资料

1. **ReAct 论文（2022）**
   https://arxiv.org/abs/2210.03629
   Agent 领域最重要的论文之一，必读。重点看 Thought-Action-Observation 的循环结构。

2. **Tree of Thoughts 论文（2023）**
   https://arxiv.org/abs/2305.10601
   ToT 的原理，理解"搜索式规划"和"贪心规划"的区别。

3. **Plan-and-Execute 模式（LangChain Blog）**
   https://blog.langchain.dev/planning-agents/
   工程化视角，讲什么时候用 ReAct，什么时候用 Plan-and-Execute。

4. **Lilian Weng 博客 - LLM Powered Autonomous Agents**
   https://lilianweng.github.io/posts/2023-06-23-agent/
   Agent 技术全景图，规划部分写得最清楚。这篇博客是圣经级别的，没读过就补上。
