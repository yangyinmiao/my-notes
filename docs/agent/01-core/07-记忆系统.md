## 推荐学习资料

按顺序看：

1. **LangChain 官方文档 - Memory 章节**
   https://python.langchain.com/docs/concepts/memory/
   最系统的入门，直接看概念部分，不用跟着写代码。

2. **《Building LLM Powered Applications》第5章 Memory**（Valentina Alto 著）
   讲得比文档更有体系感，重点看 short-term vs long-term 的区别。

3. **MemGPT 论文（2023）**
   https://arxiv.org/abs/2310.08560
   理解"分层记忆"思路，比直接堆 RAG 更接近真实 Agent 设计。

4. **Zep 和 Mem0 的 GitHub README**
   https://github.com/getzep/zep
   https://github.com/mem0ai/mem0
   看架构设计，不用深入代码。

## 二、四类记忆

| 类型 | 类比 | 存储位置 | 生命周期 |
|------|------|---------|---------|
| Sensory Memory | 感知 | Context Window | 当前轮次 |
| Short-term Memory | 工作记忆 | Context Window / 对话历史 | 当前会话 |
| Long-term Memory | 长期记忆 | 外部数据库 / 向量库 | 持久化 |
| Episodic Memory | 经历记忆 | 结构化存储 | 持久化 |
