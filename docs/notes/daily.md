## 2026-05-19
- 今天学习了使用CC-switch，适配了claude code，遇到了一个问题，就是claude code会经常封号，所以使用cc-switch去适配国内的大模型，按照教程配置cc-switch，适配的是阿里云的百炼大模型，发现有几个坑：
    - 1. 需要在API参考文档中详细看下支持模型是哪些
    - 2. claude code默认的max_tokens是1M，但是千问系列支持的是8196的，所以要在cc-switch的配置文件中env增加ANTHORPIC_MAX_OUTPUT_TOKENS  参数，否则会出现请求失败的情况
- 今天还学习了vibe coding的技巧：
    - 核心就是先仔细思考自己想要什么，想清楚了再用自然语言描述给AI
    - 确定架构
    - 做好版本控制，方便后续出错了回滚，多多使用git commit
    - 在调试错误的时候，尽可能给出更多的信息，想想怎么样才能让AI解决这个问题，自己也要深入了解系统，缩小范围，推测可能的原因帮助AI解决问题
    - 上下文尽可能提供更多的细节、信息、上下文，输入具体的产品文档、环境信息、你的倾向，示例，或者精心打磨的上下文，这些都能帮助AI确定更好的效果
